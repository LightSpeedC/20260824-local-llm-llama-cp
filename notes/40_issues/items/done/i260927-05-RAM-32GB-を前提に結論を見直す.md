RAM を 32GB に増設し、画面表示を内蔵GPU に任せたところ、CPU 側に重みを置くモデルが大きく速くなった （Qwen3.5-9B 8.1 → 14.6 tok/s、gpt-oss-20b 5.9 → 19.0 tok/s）。KV を q8_0 にすればコンテキスト 16384 も使える。 実行計画の結論と方針は RAM 16GB の実測に基づいたままで、再測定と合わなくなっている。

- [済] RAM と VRAM に左右されるものを 32GB で測り直し、実行計画・調査に追記する
- [済] 実行計画の結論と方針（gpt-oss-20b の位置づけ、コンテキストの上限）を見直す
- [済] gemma-4-E4B を測り直す（CPU 側に置く PLE が速くなる可能性がある。生成は 45.23 → 46.87 tok/s でほぼ同じ、pp512 は 1149 → 1843 tok/s）
- [済] Qwen3-30B-A3B を取得して測る（UD-Q4_K_XL・16.5 GB。Claude Code の読み書きの試験に合格。生成は `-ncmoe 40` で 16.6 tok/s、39 以下は VRAM があふれて落ちる）
- [済] Claude Code 用のモデルを gpt-oss-20b で試す（25 分でタイムアウト。10GB 未満の 13 本も試し、[試験の経緯と全実行の記録](../../../01_research/r260930-01-エージェント試験の経緯と全実行の記録.md)に記録）
