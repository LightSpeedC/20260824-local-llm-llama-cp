## 3. 更新の手順

1. 今の版を測る (llama.cpp・node・bun・Claude Code・OpenCode・Pi・NVIDIA ドライバ)。引継ぎにあった環境の変化を先に押さえる
2. 最新の版を調べ、ダウンロードするファイル名・取得元・サイズを示して承認をもらう
3. 1 つずつ上げる。上げるたびに、gemma-4-E4B で Claude Code の読み・書き (`test-cc-tools.ps1 -Only gemma-4-E4B-it-Q4_K_M -Tests read,write`) を流す
    1. llama.cpp: CUDA・Vulkan・CPU 版を `bin/llama.cpp-b<新版>-*` に置き、b11609 を消す。`paths.ps1` とスクリプトの版を直す。`llama-bench` の値を前の版と比べる
    2. node・bun
    3. Claude Code・OpenCode・Pi
4. 10/17 から続く、読みの時間切れが新しい版で直るかを見る。直らなければ、サーバのログ・Vulkan 版で切り分けを続ける
5. 結果を[試験結果](../01_research/r260929-01-AIエージェントの試験結果.md)に書く。版で動きが変わったら、[AIエージェントの特徴](../01_research/i261014-01-AIエージェントの特徴.md)も直す

## 4. ツールの統合

**今ある動き:** `start-agent.ps1` は、モデル名の一部とエージェントを引数で受け取る。差し替えたテンプレートがあれば使う。ポートが使用中なら止める。エージェントの窓を閉じたら llama-server も止める。エージェントのホームを作業用の場所に分ける。`server` と `bench` も選べる。直したあとも、これらを同じ手順で確かめる。

### 変えること

- `-Model` を省いたら、`C:\AI-models` を探して gguf (mmproj を除く) を一覧にする。番号・サイズ (GB)・モデル名を出し、番号で選ばせる
- `-Agent` を省いたときも、一覧から番号で選ばせる
- ポートは、引数 → 環境変数 `LLM_PORT` → 11434 の順で決める
- 引数を全部渡したときは、今と同じく聞かずに動く (試験から呼ぶため)
- `start-agent.cmd` から引数なしで起動できるようにする

### 消すもの

- `run-server.cmd`・`run-server-9b.cmd`・`run-server-cc.cmd`・`run-server-e4b.cmd`・`run-server-moe.cmd`
- 消したあと、`text find` で古い名前を探し、README・資料・スクリプトに残っていれば直す
