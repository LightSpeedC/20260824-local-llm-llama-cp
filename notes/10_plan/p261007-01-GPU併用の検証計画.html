この文書の位置づけ

きっかけは、Intel GPU の試験で、Vulkan 版から NVIDIA GPU も見えていて、モデルの一部が NVIDIA に載っていたこと（試験結果の「Intel GPU で流した結果」）。混ざったときの速さは測っていないので、併用で速くなるかを改めて測る。

目的

この PC には、NVIDIA GeForce RTX 3050 Ti Laptop GPU（VRAM 4GB）と Intel Iris Xe（メインメモリを共有、最大約 16GB）がある。 いまの使い方は、NVIDIA GPU を使うときは CUDA 版で NVIDIA と CPU に分け、Intel GPU を使うときは Vulkan 版で Intel だけに載せる。 llama.cpp の Vulkan 版は 2 つの GPU を同時に使えるので、4GB に収まらないモデルを NVIDIA・Intel・CPU に分けて載せたときに、どれだけ速くなるかを測る。

速くなる構成が見つかれば、この PC で使うときの既定（start-agent.ps1 と試験スクリプト）に入れる。閉域網の PC には NVIDIA GPU が無いので、配布物の既定は変えない。

比べる構成

記号llama.cpp載せ方引数
CCPU 版CPU だけ（なし）
NCUDA 版NVIDIA と CPU（いまの NVIDIA の既定。大きいものは自動配置）-ngl なし（3.2GB 以下は -ngl 99）
IVulkan 版Intel だけ（いまの Intel の既定）-ngl 99 --device Vulkan0
INVulkan 版Intel と NVIDIA に層を分ける-ngl 99 --device Vulkan0,Vulkan1 --tensor-split に比を渡す（例: 12,3・10,3・8,3）
INCVulkan 版Intel と NVIDIA に分け、MoE の専門家の重みは CPU に置くIN に -ncmoe（MoE のモデルだけ）
NC-vkVulkan 版NVIDIA と CPU（Vulkan 版で N と同じ形。CUDA 版との差を見る）--device Vulkan1、-ngl なし

CUDA 版は Intel GPU を使えないため、NVIDIA と Intel を同時に使えるのは Vulkan 版だけ。

測り方

  1. 速さ: llama-server を各構成で立て、同じプロンプトを送って、応答の timings からプロンプトの処理（tok/s）と生成（tok/s）を読む。プロンプトは、エージェントが最初に送る量に近い約 20,000 トークンと、短い約 600 トークンの 2 つ。生成は 128 トークン。キャッシュは使わない（cache_prompt: false）。各 3 回の中央値
  2. 載り方: サーバのログ（-lv 4）から、デバイスごとに載った層の数と大きさを記録する
  3. 使えるか: 速さで上位の構成について、sum の試験（Claude Code・Pi・OpenCode）を 1 回ずつ流し、合否と時間を見る

文脈は試験と同じ 65,536、KV キャッシュは CPU 側（-nkvo -ctk q8_0 -ctv q8_0 -fa on）。KV を GPU に置く形は、併用で速くなった構成でだけ追加で測る。

測るスクリプトは tools/50_run/bench-devices.ps1 として作る（構成とモデルを引数で渡し、結果を logs/bench-devices/ に JSON で残す）。

進め方

  1. Intel GPU だけの試験（2026-10-07 開始、55 組）が終わるのを待つ。GPU を取り合うと、どちらの結果も狂う
  2. bench-devices.ps1 とテストを作る
  3. 4 本 × 6 構成（IN は比を 3 通り）の速さを測る。-ncmoe は MoE の 2 本だけ
  4. 速さで上位の 1〜2 構成で sum の試験を流す
  5. 結果を試験結果に書き、速くなる構成があれば、この PC の既定に入れるかを決める

気をつけること

  • Intel GPU の共有メモリは、メインメモリ（32GB）から取る。Intel に多く載せるほど、CPU 側に置く層・KV キャッシュ・エージェントが使えるメモリが減る。測るときは空きメモリも記録する
  • 2 つの GPU の間のやりとりは、メインメモリを経由する。層を分けると、トークンごとにデータが行き来する。生成が速くならず、遅くなることもありうる（未確認）
  • 遅い側に全体が引きずられる。層の分け方（--tensor-split）は、速さの比ではなくメモリの比で配られるため、比を何通りか試す
  • ノート PC なので、電源につなぎ、休止しない設定にしてから流す。熱で速さが落ちることがあるので、構成の順番を入れ替えて 2 周目も測る
  • Vulkan のデバイスの番号（Vulkan0・Vulkan1）は PC によって変わる。スクリプトは名前（Intel・NVIDIA）で選ぶ
