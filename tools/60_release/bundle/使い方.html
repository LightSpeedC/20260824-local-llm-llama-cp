持っていくもの

このファイルが入っているフォルダ（llm-bundle-yyyyMMdd）を、丸ごとコピーする。中から一部だけを取り出さない（exe は同じフォルダの DLL を使う）。

フォルダ・ファイル中身
run\ダブルクリックで動かす cmd（第 3 章）
config.cmd場所の設定。モデルを別の場所に置くときだけ書き換える（第 2 章）
models\モデル 4 本（gemma-4-E4B・gemma-4-E2B・Ministral-3-3B・gemma-4-12B-QAT）
bin\llama.cpp-b11320-vulkan\llama.cpp（Intel GPU を使う版）
bin\llama.cpp-b11320-cpu\llama.cpp（CPU だけの版）
bin\llama.cpp-b11320-cuda\llama.cpp（NVIDIA の GPU を使う版）
bin\node\Node.js v26.10.0。中に Claude Code・Pi・OpenCode が入っている。インストールは要らない
bin\claude\claude.exeClaude Code の単体版
installers\Node.js の msi（PC に入れて使いたいとき）と Intel GPU のドライバ

README.html・notes\このプロジェクトの資料（試験の結果・計画・課題）。README から順にたどれる

work\（エージェントの作業フォルダ）と logs\（試験の結果）は、動かしたときにできる。

置き方と設定

置き場所はどこでもよい

Y:\llm-bundle-20261002 でも D:\llm\llm-bundle-20261002 でもよい。中の cmd とスクリプトは、自分の置き場所から相対で全部を探す。 フォルダの名前に空白を入れない。

モデルを別の場所に置くとき

モデルを models\ に置くなら、設定は要らない。 すでに別の場所にモデルがあるときは、config.cmd をメモ帳で開き、LLM_MODEL_DIR の行だけを書き換える。サブフォルダに分かれていてもよい（下の階層まで探す）。 

set "LLM_MODEL_DIR=%~dp0models"

を、たとえば次のようにする。

set "LLM_MODEL_DIR=C:\AI-models"

使う llama.cpp を決めるとき

LLM_BACKEND=auto（既定）は、Intel GPU が見えれば Vulkan 版、見えなければ CPU 版を使う。 固定したいときは llama.cpp-b11320-vulkan・llama.cpp-b11320-cpu・llama.cpp-b11320-cuda のどれかを書く。

動かす順番

run\ の cmd をダブルクリックする。終わると「続行するには何かキーを押してください . . .」（英語の Windows では Press any key to continue . . .）で止まるので、結果を読んでから閉じる。

  1. list-devices.cmd — Intel GPU が見えるかを確かめる。Vulkan0: Intel(R) Iris(R) Xe Graphics のように出ればよい
  2. bench-gemma-4-E4B-it-Q4_K_M.cmd — Vulkan 版と CPU 版で速さを測る。表の pp512（入力の処理）と tg64（生成）が 1 秒あたりのトークン数
  3. pi-gemma-4-E4B-it-Q4_K_M.cmd — llama-server を立てて Pi を開く。日本語で頼みごとを書いて使う。Pi を閉じると llama-server も止まる

cmd の種類

名前は <種類>-<モデル>.cmd。モデルは 4 本それぞれにある。

種類すること
pi-Pi を開く
opencode-OpenCode を開く
claude-Claude Code（npm 版）を開く
claude-exe-Claude Code（単体の claude.exe）を開く
server-llama-server だけを開く（接続先は http://127.0.0.1:8080/v1）。止めるときは Ctrl+C
bench-Vulkan 版と CPU 版で速さを測る

エージェントは work\project の中で作業する。エージェントの設定は work\agent-home\ に置き、その PC のいつもの設定には触れない。

どれを使うか（開発用の PC での試験から）

  • Pi と gemma-4-E4B がいちばん安定していた。Intel GPU で約 40 秒、CPU だけで約 50 秒で、プログラムを書いて実行するところまでできた
  • Claude Code は毎回長い指示文をモデルに読ませるため、Intel GPU で 5 分前後かかる。CPU だけでは 10 分で終わらなかった
  • gemma-4-12B-QAT は賢いぶん遅い。メモリが 16 GB の PC では苦しい

試験を流す

「1から10までの合計を表示するnode.jsプログラムをsum.jsに書く。node sumで実行する」を頼み、書けて・実行できて・55 と答えたら合格。 コマンドプロンプトで、配布物のフォルダに移ってから実行する。 

cd /d Y:\llm-bundle-20261002
tools\50_run\test-agents.cmd -Agent pi -Only "gemma-4-E4B" -UseTemplates -Tests "sum"
tools\50_run\test-agents.cmd -Agent opencode -Only "gemma-4-E4B" -UseTemplates -Tests "sum"
tools\50_run\test-cc-tools.cmd -Only "gemma-4-E4B" -MaxSizeGB 20 -UseTemplates -NoRules -Tests "sum" -ExtraArgs "--reasoning off"
  • -Only はモデルの名前に含まれる語。カンマで区切ると複数を順に流す（例: "gemma-4-E2B,gemma-4-E4B"）
  • -Tests "echo,sum" にすると、日本語がエージェントに届くかの確認も流す
  • 結果は 1 件ごとに画面に出て、logs\ にも残る。1 問の上限は 10 分

うまく動かないとき

起きたこと見るところ
list-devices.cmd で GPU が出ないIntel GPU のドライバが古いか、Vulkan に対応していない。そのままでも CPU 版で動く（auto なら自動で CPU 版になる）。ドライバは installers\drivers\ にある（入れるかはその PC の管理者が決める）
GPU の名前が UHD Graphics と出るメモリが 1 枚だけのことがある。2 枚にすると Iris Xe になり、速くなる
「モデルが見つかりません」config.cmd の LLM_MODEL_DIR が、モデルのある場所を指しているか
「llama-server が起動しません」メモリが足りないことが多い。小さいモデル（E2B・E4B）にする。ログは logs\start-agent\ にある
cmd がすぐ閉じる・何も出ないコマンドプロンプトを開き、配布物のフォルダで cmd の名前を打って実行すると、エラーが読める
Claude Code は Anthropic の利用条件に従う。 社内の閉域網で使ってよいかを確かめてから使う。
